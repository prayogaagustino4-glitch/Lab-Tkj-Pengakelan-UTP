Panduan Praktikum Lab Maya TKJ

Modul ini mensimulasikan cara kerja protokol ICMP (Internet Control Message Protocol) dalam menguji konektivitas jaringan dan melacak rute paket melewati 3 hop perangkat jaringan.

1. Perintah CLI yang Didukung:
  • ping [ip_tujuan] — Mengirim 4 paket ICMP Echo Request ke IP tujuan.
  • ping [ip_tujuan] -t — Mengirim paket ping terus-menerus hingga dihentikan (Ctrl+C atau stop).
  • tracert [ip_tujuan] / traceroute [ip_tujuan] — Melacak rute hop demi hop menggunakan kenaikan nilai TTL (Time to Live).
  • ipconfig / ifconfig — Menampilkan konfigurasi alamat IP perangkat PC Client.
  • clear / cls — Membersihkan layar terminal.
2. Skenario Target IP untuk Diuji:
  • 192.168.1.2 — Switch L2/L3 (Hop 1): Latensi sangat rendah (~2 ms), TTL=64.
  • 192.168.1.1 — Gateway Router (Hop 2): Latensi rendah (~6 ms), TTL=64.
  • 10.10.10.1 — Server Utama (Hop 3): Latensi sedang (~18 ms), TTL=62.
  • 8.8.8.8 — DNS Publik / Cloud (Hop 3): Latensi internet (~34 ms), TTL=56.
  • 192.168.1.99 atau IP tak dikenal — Host Offline / Unreachable: Menghasilkan Request Timed Out (RTO) dengan 100% Packet Loss.
